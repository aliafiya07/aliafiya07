## 🚀 Projects

### 🛣️ [RoadGuard](https://github.com/aliafiya07/RoadGuard)
Municipal road-damage workflow prototype. Citizens report damaged roads with photos and location; administrators track each report through a repair workflow, manage the fleet, and view live vehicle positions on an OpenStreetMap-based map.
**Stack:** React, Vite, Express, Firestore, Socket.IO, Leaflet, JWT

### 🔒 [Air-Gapped AI Code Verifier](https://github.com/aliafiya07/Air-Gapped-AI-code-Verifer-)
Full-stack MERN app for scanning codebases and verifying fixes entirely offline, so no code or data leaves the network. Built for regulated environments where cloud APIs are not an option.
**Stack:** MongoDB, Express, React, Node.js

### 🏡 [BlockLand](https://github.com/aliafiya07/BlockLand)
Full-stack platform that improves land-ownership transparency and property verification using blockchain technology.
**Stack:** Next.js, React, TypeScript, Blockchain

### 🏥 [Chikitsakendra](https://github.com/aliafiya07/Chikitsakendra-)
AI-powered healthcare management platform connecting patients and doctors through a secure, user-friendly system, with MySQL data persistence and Node.js/Express REST APIs.
**Stack:** Node.js, Express, MySQL, HTML
